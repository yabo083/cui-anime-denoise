# 视觉规范（v1）

原则：**画布是主体，界面退后**。所有装饰subtract，所有强调只在需要被点的地方。

## 1. 诊断（当前界面的问题）

| 位置 | 现在 | 为什么不对 |
|---|---|---|
| 侧栏滑杆 | 轨道整条珊瑚色 | 一屏 5 条红色进度条，强调被稀释成背景噪声 |
| 分区标题 | 12.5px 与正文同色同重 | 层级只差 0.5px，眼睛找不到分组边界 |
| 分组间距 | 全部 8–14 | 组内与组间同距，“去噪强度/局部保护/队列”糊成一段 |
| 画布底 | 18px 棋盘格，对比约 12% | 棋盘格的视觉重量超过作品本身，注意力被抢 |
| 对比分隔线 | 灰圆无提示 | 不知道可拖动；也没有“哪边是什么”的标签 |
| 文件头行 | 文件名+状态+尺寸+耗时+预缩+L0+两个按钮 | 一行塞 7 类信息，主次不分 |
| 数字 | 60% / 0.0010 与正文同重 | 数值是本工具的核心输入，却没有视觉位置 |
| 队列卡 | 选中项整块强调色描边 | 选中态过重，抢过画布里的选中对象 |
| 缩略图条 | 与画布同底 | 分不清“画布”与“文件列表”的边界 |

## 2. 视觉方向

**“暗房工作台”**——深/浅两套中性色，画布是唯一有内容的区域，控件全部低对比；强调色只出现在**可点的主操作**与**当前选择**上。

三条手法：
1. 中性色四层（背景 / 面板 / 输入 / 描边），相邻层亮度差 ≤ 6%，靠**1px 描边**分界，不靠阴影。
2. 强调色面积 ≤ 全屏 3%：主按钮、当前工具、选中瓦片环、拖动中的滑杆。
3. 数字统一 tabular，用中等字重；单位小一号、muted。

## 4. 字阶（4 级）

| 级 | 值 | 用途 |
|---|---|---|
| caption | 11 | 路径、单位、次要说明（muted） |
| body | 12.5 | 正文、列表、按钮 |
| label | 12.5 medium + 次文字色 | 分区标题、滑杆标签 |
| title | 15 medium | 文件名、对话框标题 |

数值：body 尺寸 + tabular，单位用 caption。行高 1.5。

## 5. 间距阶

4 / 8 / 12 / 16 / 24。规则：**组内 8、组间 18–24**；面板内边距 12–16。

## 6. 布局调整

1. 文件头行只留：文件名（title）+ 状态徽标 + 右侧动作（保存/打开目录）。
   尺寸、耗时、预缩、L0 移到**底部状态行**（caption）。
2. 工具栏分三簇，簇间用 1px 线：`对比/原图/结果` ｜ `笔刷/橡皮/套索` ｜ `撤销/重做/清除` ｜ 右侧 `缩放簇`。
3. 画布底：`SURFACE_MUTED`，24px 棋盘、对比 ≤ 4%；圆角 12、1px 描边。
4. 对比视图：左上/右上角 `原图` / `结果` 标签（黑 55% 底、白 11px、圆角 6、内边距 4×8）；分隔线 2px 白、中间 3 点抓手、hover 时线加粗到 3px。
5. 缩略图条：`SURFACE` 底 + 顶部 1px 描边；瓦片 62×62、圆角 12（与「添加」瓦片同一绘制函数）；选中 = 2px 强调色环 + 2px 间隙，不填色。
6. 队列卡片：选中 = 1px 描边 + `SURFACE_MUTED` 底，不用强调色描边。

## 8. 图标规则

只用于**动作**与**状态**，不用于装饰；尺寸 14（行内）/16（按钮）/20（空状态、瓦片占位）；与文字间距 6；同一行最多 4 个图标按钮。

## 9. 自检清单

1. 一屏只有一种强调色，且总面积 < 3%。
2. 分区标题与正文可一眼区分（颜色 + 字重，不靠字号）。
3. 组内 8、组间 ≥18。
4. 画布是屏幕上对比最强的区域。
5. 数字全部 tabular，单位更小。
6. 选中态只有一处（瓦片环 / 队列卡 / 工具按钮三选一场景不共存）。
7. 对比视图左右各有标签。
8. 分隔线可见且在 hover 时变粗。
9. 任何控件不靠阴影表达层级。
10. 1000×700 下侧栏不出现横向滚动，画布仍 ≥ 360px 高。
