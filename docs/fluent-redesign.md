# Fluent 重设计规范（v2 视觉与交互的唯一来源）

取代 `docs/visual-design.md`。原则：**Canvas-First**——画布是唯一主体，控件按需出现；
主层（Layer 1）独立完成"拖入 → 去噪 → 看对比 → 保存"全流程；高级操作进入第二层（Layer 2），用完即走。

## 1. 布局（Layer 1 主层）

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 40px：图标 · 应用名 · 当前文件名(点击→打开所在目录)      │
│             [● RTX 5060 Ti]  [⚙] [?]        [─][□][×]       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                        主画布（图片）                          │
│              左下/右下可选：图片尺寸 · 耗时 · 参数              │
│                                                              │
│        ┌─ 缩略图托盘（仅多图时出现，68px，悬浮在控制条上方 8px）─┐│
│        └──────────────────────────────────────────────────┘ │
│           ┌─ 悬浮主控制条 44px 高，居中，距底 24px ─┐          │
│           │ [轻柔|推荐|强力] │ [对比|原图|结果] │      │          │
│           │ [微调⚙] [画笔] │ [另存为(accent)]      │          │
│           └──────────────────────────────────────┘          │
└──────────────────────────────────────────────────────────────┘
```

- **无左侧栏**。窗口最小 900×560。
- 主控制条内容随状态裁剪：空状态与"无结果"时只留分段强度与添加引导；无图片时隐藏。
- 文件名点击 → ShellExecute 打开所在文件夹并选中文件（等价原工具的 reveal）。

## 2. 四种状态

1. **空状态**：整窗 Mica 底；中央卡片（Lucide `images` 描边图标 48px + "拖入图片、点击浏览或 Ctrl+V 粘贴" + 副文案"支持批量队列"）。整窗任意位置接受拖放。
2. **处理中**：中央 `cui_progress_ring` + 阶段文字（"超分…/L0 平滑…"）；微调参数触发的快速重跑（≤1.5 s）不盖遮罩，改为控制条上缘 2px 不定进度条 + 完成后结果纹理 120ms cross-fade。
3. **完成对比**：默认分割视图；分割线 2px 白 (a=0.85)、双侧 1px 羽化阴影、中心 28px 圆形手柄（白底 + 阴影，hover 放大 10%）；左上/右上角各贴"原图"/"结果"标签（黑底 55%、白字 11px、圆角 6）。
4. **多图队列**：缩略图托盘滑出（200ms），瓦片 48×48 + 6px 间距 + 4px 内边距，状态角标（排队=灰点 / 处理中=进度环 / 完成=✓），当前项 2px accent 描边；hover 出 ×；两端 < > 翻页；←/→ 键切换。

## 3. Layer 2（高级层）

| 功能 | 形态 | 进入 | 退出 |
|---|---|---|---|
| 参数微调 | `cui_popover` 浮层 260px，锚点=控制条微调钮，向上弹 | 点击微调图标 | Light-dismiss / Esc / 再点 |
| 局部保护 | 沉浸模式：主控制条下沉收起，顶部滑入 44px 保护工具条 | 画笔图标或 `B` | 工具条上 [完成](accent) / [取消] / Esc |
| 全局设置 | `cui_sheet` 右侧抽屉 320px | 标题栏 ⚙ | 抽屉关闭钮 / Esc |
| 快捷键说明 | `cui_dialog` | 标题栏 ? 或 `?` | Esc / 关闭钮 |
| 未保护结果查看 | 保护模式工具条内的一个视图项 | 点击"未保护" | 再点 |

- 微调浮层：预缩比例滑杆（30–100%）、L0 平滑滑杆（0–0.005，显示到 4 位小数）、重置默认。松手重跑；仅改 L0 时复用 SR 缓存。
- 保护工具条：`[画笔|橡皮|套索]` ｜ 笔刷大小滑杆 ｜ 恢复比例滑杆（%）｜ 柔边滑杆 ｜ 撤销/重做 ｜ 显示范围（眼睛）｜ 反选 ｜ 清除 ｜ 未保护结果 ｜ [取消] [完成]。
- 设置抽屉：外观（跟随系统/浅色/深色 `cui_segmented`）、画布背景（纯色/毛玻璃 `cui_segmented`，毛玻璃默认）、输出文件夹（路径 + 浏览）、推理设备（自动/GPU/CPU `cui_select`）、模型管理（CUGAN/APISR 下载状态 + 下载按钮 + 进度）、自动更新开关、版本与开源许可入口、诊断包导出。

## 5. 圆角 / 间距 / 字阶 / 控件尺寸

- 圆角：FULL(胶囊)=999；LG=10（浮层）；MD=6（分段滑块、图标钮、缩略图）；SM=4（滑杆拇指、tooltip）。
- 间距：2/4/8/12/16/24/32，组内 8、组间 ≥16。
- 字阶（HarmonyOS Sans SC）：Title 18/24 Bold；Subtitle 14/20 Medium；Body 13/18；Caption 11/14。数值一律 tabular + 中等字重。
- 尺寸：标题栏 40（系统键 46×40）；主控制条 44 高/圆胶囊/距底 24；分段控件 32 高、滑块 R6；图标钮 32×32（icon 16）、紧凑 28×28（icon 14）；滑杆轨 4px、拇指 16（active 18 + 6px accent 圆点）；保护工具条 44；设置抽屉 320；浮层 260。

## 6. 动效

- 浮层/抽屉/托盘进出：200ms，cubic-bezier(0.1,0.9,0.2,1.0)，位移 8–16px。
- 分段控件滑块：spring stiffness 380 / damping 28。
- 结果纹理替换：120ms cross-fade。
- hover：`state-layer` 叠加 light `rgba(0,0,0,.04)` / dark `rgba(255,255,255,.06)`；pressed `.08/.12` + 98% scale。

## 7. 光标与阈值

- 画布默认 ARROW；空格/中键 GRAB→GRABBING；分割线 ±8px 内 SIZE_WE；保护模式隐藏光标自绘圆环（=笔刷半径）+ 1px 十字。
- 拖拽死区 3px；分割线距边缘 <24px 松开时吸附到该侧（=全图显示一侧）。

## 8. 快捷键（与原工具完全对齐）

`1/2/3` 视图（对比/原图/结果）；`X` 全屏原图↔结果互切；`Z` 按住看原图；`M` 按住看蒙版；
`B` 进入/退出画笔（橡皮时先切回画笔）；`E` 橡皮；`L` 磁性套索；`I` 反选；`Esc` 依次退出（套索放弃→退出保护→关浮层）；
`[` `]` 或空格+滚轮调笔刷；右键拖动=擦除；空格拖动=平移；Backspace 删套索锚点；Enter/双击/回起点闭合；Alt/右键闭合=减选；
`←` `→` 切图；`Ctrl+O` 打开；`Ctrl+V` 粘贴；`Ctrl+S` 另存为；`Ctrl+Z/Ctrl+Shift+Z` 撤销重做；
`F` 适合窗口；`0` 1:1；`Ctrl+=`/`Ctrl+-` 缩放；`?` 快捷键说明；`Ctrl+Q` 退出。

## 9. 行为规格（验收）

- 拖入任意张数图片 → 依次处理 → 首张自动进对比视图 → 自动存 `outputs/` → 缩略图托盘出现。
- 主层不点击任何高级入口即可完成全流程。
- 改预设/微调即重跑（L0-only ≤0.5s，SR 按 GPU 时间），处理中改参数立即中止旧任务。
- 保护模式下整套笔刷/套索/撤销/反选/显示范围/未保护结果可用，手感与原 web 版一致。
- 空状态无任何遮挡元素；处理中不锁 UI；所有浮层 light-dismiss。
- 画布背景两种：`纯色`（BG_CANVAS + 棋盘格）与 `毛玻璃`（默认）——毛玻璃取最近一次输出缩到 ~160px 后六次盒式模糊，盖 80% 主题色纱（类 Mica 取色）；无输出时回落纯色。
- 设置抽屉/对话框打开时其遮罩独占输入：画布与浮层不吃穿透来的键鼠（含滚轮缩放与进行中的笔画），点击遮罩仅关层；标题栏系统键仍然可用。
- 窗口启动 ≤0.8s 可交互；模型就绪前任务排队。

## 10. 实现偏差（随 Phase 4b 落盘记录的，与上文规范的有意出入）

规范是意图；实现里下面几处走了等效但不同的路，原因一并记下：

| 规范说法 | 实际实现 | 原因 |
|---|---|---|
| 标题栏文件名悬停提示 | 文件名做成链接，点击即资源管理器 `/select` 打开 | 提示信息密度低；「点文件名定位文件」是用户实际动作，一步到位 |
| 设备状态进设置页 | 标题栏设备胶囊常显；GPU→CPU 回退时胶囊变黄点+三角标，点击打开设置页 | 回退属于性能警告，藏进设置页用户可能永远看不到 |
| Esc 递进 | 依次：放弃未闭合套索 → 退出保护（=完成，保留编辑）→ 关微调卡 → 收回工具 | 与 §8 顺序一致；保护模式 Esc 等价「完成」，「取消」仍走工具条按钮 |
| 保护模式「取消」 | 进入保护时对整个蒙版拍快照，取消整体回滚 | 快照一次性回滚比逐笔反放撤销日志更便宜也更不易错；编辑期间 Ctrl+Z 照旧逐步可用 |
| 模型下载「可取消」 | 设置页只给下载按钮+进度条，没有取消 | denoiser 下载接口没有取消入口；模型文件 ≤数百 MB，中途打断的价值低于实现成本 |
| `?` 快捷键说明 | `/`（不按 Shift）与 `?`、F1 都开帮助 | CUI 键表按物理键上报，两个都接没有成本 |
| 空状态点击 | 点击整张空态卡 = 浏览文件（不只按钮） | 与原 web 拖放区整区可点的手感一致 |
| 托盘删除 × | 悬停瓦片右上角浮出圆形 ×，点击删除该任务 | 规范未给删除入口；多图队列需要撤销误拖的手段 |
| 吐司 | 用 CUI 原生 `cui_toast`（右下角） | 与弹层/对话框同一实现路径，省一套自绘层 |
| `X` 互切 | 对比态按 X 先进原图，再按到结果；不在对比态时原图↔结果互切 | 与原工具语义一致（X 是原图/结果二选一，不是三态轮换） |
